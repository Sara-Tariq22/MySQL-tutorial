# 📚 Learning SQL

Welcome to my SQL learning repository! This project documents my journey of mastering SQL (Structured Query Language) and relational databases. It contains a collection of scripts, notes, and exercises ranging from basic queries to advanced database operations.

This repository is organized by concepts, making it easy to track progress:

*   **`02_Intermediate/`**: Joins, Unions, `CASE`, `HAVING`, Window Functions.
