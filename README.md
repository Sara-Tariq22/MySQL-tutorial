# SQL-first-tutorial-

This repository contains a simple, hands-on tutorial exploring the fundamental SELECT statements in MySQL. Using a sample parks_and_recreation database, these queries demonstrate how to extract, manipulate, and filter data from the employee_demographics table.

Key Concepts Covered in this Tutorial:

Basic Data Retrieval: Using SELECT * to pull all records and columns from a table.

Specific Column Selection: Querying only the necessary columns (e.g., first_name, last_name, age) for cleaner data outputs.

Mathematical Operations: Performing basic arithmetic directly within a query (age + 10) * 10 + 10 to manipulate numerical data on the fly.

Unique Values: Using the DISTINCT keyword to filter out duplicates and return only unique values (e.g., finding all unique entries in the gender column).
